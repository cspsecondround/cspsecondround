# CSP 第二轮模板

CSP 第二轮（CSP-S Round 2）常用算法模板合集。主站发布在博客园，这里放一份阅读体验更佳的版本。

## 关于名字

博客园账号是 [Accepted01](https://www.cnblogs.com/Accepted01/)，GitHub 上名字 `Accepted01` 已被占用，所以这个仓库叫 `cspsecondround`，不是另一个人开的号。

## 内容

- 排序：冒泡、选择、插入、归并、快速
- 二分：二分查找、左边界、右边界
- STL：string / vector / map / set / list / stack / queue / priority_queue
- 基础 DP：01 背包、完全背包、LIS、LCS
- 图论：Dijkstra、SPFA、Bellman-Ford、Floyd、Kruskal、Prim、Tarjan
- 数据结构：线段树、树状数组、平衡树、主席树
- 字符串：KMP、Manacher、哈希、Trie
- 数学：快速幂、扩展欧几里得、乘法逆元、CRT、线性筛
- 等等

完整版带在线编辑器，见 GitHub Pages：

**https://cspsecondround.github.io/cspsecondround/**

## 说明

- 模板按常见写法整理，不保证对所有题目最优，遇到具体题目该改还是得改。
- 欢迎提 issue 指出错误，但不保证及时更新。
